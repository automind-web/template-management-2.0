# AI Management — рабочий кабинет задач

Публикация: см. **[README_SITES.md](README_SITES.md)**.

## Структура

```
/app, /components      страницы и интерфейс (React, Tailwind 4, shadcn/ui на Radix)
/app/api/[...path]     единая точка API → server/router.ts
/server                серверные операции, проверка прав (permissions.ts), сессии, пароли
/server/ops            операции: setup, auth, invites, org, system (+ задачи, статистика — следующие этапы)
/db/schema.ts          схема БД (Drizzle)
/drizzle               SQL-миграции
/config/company.ts     название, тема, статусы, переходы, правила, часовой пояс
/i18n/messages.ts      все тексты интерфейса (ru; заготовки kk, en)
/worker/index.ts       точка входа Worker (fetch, scheduled)
/.openai/hosting.json  привязки DB и BUCKET
```

## Безопасность (реализовано на этапе 1)

- Роль, филиал и членство читаются из БД **на каждом запросе** — перевод или отзыв действует со следующего запроса; при отзыве все сессии участника закрываются.
- Сессии хранятся как SHA-256 от токена; токены приглашений и кодов — тоже только хеши.
- Изменяющие запросы принимаются только со своего origin (CSRF).
- Ответы API — `Cache-Control: no-store, private`; секреты интеграций читаются только на сервере, наружу отдаётся лишь факт наличия (и только директору).
