# AI Management — рабочий кабинет задач

Кабинет задач компании с филиалами: сотрудник, руководитель филиала, директор. Один шаблон для разных
компаний — название, оформление, статусы и правила меняются настройками, а не кодом.
Интерфейс сделан по макету AI-Management-Desktop. Публикация в ChatGPT Sites — **[README_SITES.md](README_SITES.md)**.

## Возможности

| Раздел | Что есть |
|---|---|
| Вход | Свои логин и пароль (без входа через ChatGPT/Google), приглашения с ролью и филиалом, «У меня есть аккаунт», сброс пароля по ссылке от руководителя или кодом в WhatsApp, сеансы и выход |
| Задачи | Список-таблица и канбан из одного запроса, поиск (название, исполнитель, №), статусы со счётчиками, срок, исполнитель, «Мои / Все доступные», CSV; карточка с правкой на месте, чек-лист, файлы и фото (R2), комментарии, история с прежними значениями; приёмка и возврат; отмена и восстановление |
| Канбан | Перетаскивание с подсветкой доступных колонок и места переноса, форма результата/комментария, откат с объяснением; на телефоне и с клавиатуры — меню «…» |
| Конфликты | Каждое изменение несёт `version` и `opId`: повтор не создаёт второй записи, при конфликте — актуальное состояние, введённый текст сохраняется |
| Клавиши | `/` — поиск, `Ctrl+Enter` / `⌘+Return` — сохранить, `Enter` — открыть, `Esc` — закрыть, `?` — подсказка; IME и удержание клавиши учтены |
| Статистика | Период, филиал, исполнитель, пояс, срез; открытые, ждут приёмки, просрочено, выполнено/не выполнено с исходными числами, вовремя/поздно, медиана скорости с n, заранее; «По сотрудникам»; каждое число открывает исходные задачи |
| Уведомления | Входящие, каналы (кабинет, WhatsApp, push), события, напоминания до срока, тихие часы, рабочие дни, пауза, установка приложения (PWA) |
| Помощник | Чат в стиле WhatsApp: команды без модели или GPT (tools) по ключу; голос; выбор карточки при нескольких совпадениях; отмена и массовые изменения — только после «да»; у директора — только личные задачи |
| WhatsApp | Whapi: привязка номера одноразовым кодом, те же операции помощника, отдельная история, уведомления и код восстановления |
| Настройки (только директор) | Компания (название, логотип, цвет, город, рабочие дни, проверка задач, видимость коллег), филиалы, сотрудники (приглашения, роли, номера WhatsApp, доступ), помощник (ключи WhatsApp и OpenAI, уровень, пожелания). Руководитель видит только «Сотрудники» своего филиала |

## Структура

```
/app, /components        страницы и интерфейс (React, Tailwind CSS 4, shadcn/ui на Radix)
/components/settings     вкладки «Настроек системы»
/app/api/[...path]       единая точка API → server/router.ts
/server                  серверный слой: права (permissions.ts), сессии, пароли, настройки, время
/server/ops              операции: setup, auth, invites, org, tasks, stats, director (для будущего плагина)
/server/notify           очередь уведомлений, настройки участника, web push (aes128gcm + VAPID)
/server/assistant        помощник: действия, команды, GPT (tools), диалоги, разбор дат
/server/whatsapp         Whapi: отправка, вебхук, привязка номера
/db/schema.ts            схема БД (Drizzle); /drizzle — SQL-миграции
/config/company.ts       значения по умолчанию: название, тема, статусы, переходы, правила, пояс
/i18n/messages.ts        все тексты интерфейса (ru; заготовки kk, en)
/public                  PWA: manifest.webmanifest, sw.js, иконки (scripts/make-icons.mjs)
/worker/index.ts         Worker: fetch (+ обработка очереди после ответа) и scheduled
```

Сайт, веб-чат и WhatsApp используют один слой операций (`server/ops`). Для плагина директора готовы
операции в `server/ops/director.ts`: поиск задач и исполнителей, назначение и переназначение,
проверка результата, сводка и детализация (сам плагин не входит в проект).

## Значения по умолчанию (где данных в ТЗ не было)

| Параметр | Значение | Где менять |
|---|---|---|
| Часовой пояс | `Asia/Almaty` | «Настройки → Компания» |
| Срок без времени | наступает в 23:59 (конец минуты) по поясу компании | «Компания» |
| Приглашение | 72 часа (1–720), подсказка имени подставляется в форму | «Сотрудники» |
| Сессия | 30 дней, продлевается при активности; cookie `am_sid` HttpOnly, Secure, SameSite=Lax | `companyConfig.auth` |
| Пароль | PBKDF2-SHA256, соль 16 байт, 100 000 итераций (максимум Web Crypto в Workers), от 8 символов | `companyConfig.auth` |
| Перебор паролей | 8 ошибок → блокировка на 15 минут | `companyConfig.auth` |
| Сброс пароля | ссылка от руководителя (своим сотрудникам) или директора — 24 ч; код в WhatsApp — 15 мин | — |
| Статусы | Новая → В работе → На проверке → Завершена (+ «Отменена»), приёмка включена | «Компания» |
| Результат при сдаче | текст обязателен, вложение — по флагу задачи | в задаче |
| Принять результат | руководитель, директор, постановщик (личную задачу сотрудник принимает сам) | `config/company.ts → transitions` |
| Возврат, повторное открытие | только с комментарием | `transitions[].requires` |
| Видимость коллег | выкл. | «Компания» |
| Время выполнения | от начала работы до завершения | `config/company.ts` |
| Напоминания | за 1 день и за 1 час, «срок прошёл»; тихие часы 21:00–08:00 (вкл.) | у каждого участника в «Уведомлениях»; по умолчанию — `config/company.ts` |
| Вложение | до 20 МБ; картинки открываются в браузере, остальное скачивается | `companyConfig.files.maxSize` |
| Модель помощника | `gpt-4.1-mini`, распознавание голоса `gpt-4o-mini-transcribe` | «Помощник» / `config/company.ts` |
| Список задач директора | по умолчанию «Все филиалы»; создание — с выбором филиала | — |

## Проверка

```bash
npm ci
npm run build        # сборка + проверка артефакта
npm run db:check     # миграции с нуля на пустую БД, без данных
npm test             # юнит-тесты: пароли, сроки, даты помощника, web push
npm run smoke:all    # все сквозные сценарии на чистой локальной БД (только для разработки)
```

`smoke:all` пересоздаёт локальную D1, временно подставляет тестовые `.dev.vars` (свой файл возвращается)
и проверяет: первый запуск и изоляцию, путь задачи и конфликты, уведомления, статистику (сверка с исходными
задачами), помощника и WhatsApp на заглушке Whapi.

## Отличия от ТЗ и макета

- Соисполнение (несколько исполнителей одной задачи) и дополнительные поля задачи не реализованы — в схеме есть `extra_json`, флагов в конфигурации нет.
- Токен Whapi и ключ модели задаются только в секретах сайта (по ТЗ), а не в форме «Подключений», как в макете.
- Обмен с реальным WhatsApp и OpenAI проверяется после задания секретов: в среде разработки проверены заглушка Whapi и режим команд помощника.
